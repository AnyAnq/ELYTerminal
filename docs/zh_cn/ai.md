# AI 助手

[English](../en_us/ai.md) / 中文

点击 Ely，在主窗口内打开或隐藏助手面板。点按仍会抚摸她；拖动只移动位置，不打开面板。看不到她时，可在设置 → 终端 → Ely 中打开。

1. 打开设置 → AI 模型，或点击助手面板的齿轮按钮。
2. 填写配置名称、服务地址和模型标识。地址可以是 `https://api.openai.com/v1` 这样的基础地址，也可以是完整的 `/chat/completions` 地址。服务需要支持兼容 OpenAI Chat Completions 的流式响应。
3. 按服务要求填写 API Key。密钥存入系统凭据库，设置文件只保存模型信息。密钥留空会保留该地址已保存的密钥；“清除已保存密钥”会删除它。本地服务可以不填密钥。
4. 先保存，再测试连接。测试会检查流式聊天、函数调用，以及收到工具结果后的回复。不支持完整工具流程的服务会标为“仅聊天”。更换地址、模型或密钥后，请重新测试。
5. 在助手面板选择模型，预览附带的上下文，描述问题并发送。

助手面板中，模型选择旁有“自动允许”开关，默认关闭。开启后，当前待确认的操作会继续，后续操作不再逐次询问，包括删除、安装、推送等命令。开关会保存；关闭后，后续需要确认的命令重新询问。悬停在开关上可查看说明。开启期间仍受目标窗格、停止、手动接管及 30 次调用限制。请只对信任的任务开启，已完成修改不会撤销。

“仅聊天 · 请先测试工具调用”表示当前配置还没有通过工具验证，并不表示该模型本身不支持工具。“仅聊天 · 当前终端不支持执行”表示模型已可用，但此窗格不能自主执行。DeepSeek 思考模式使用自动工具选择，并把服务要求的 `reasoning_content` 随后续工具消息回传；工具验证失败会显示具体错误。升级后请重新测试曾经显示“仅聊天”的配置。

每次新请求都会附带该窗格的 shell、项目目录、当前可见终端内容、最近 200 行和选中文本。“预览终端上下文”会刷新这些内容。终端文字会发送给选中的服务，发送前请检查其中是否有敏感信息。

Windows 下，加载了集成脚本的 Windows PowerShell、pwsh 和 cmd 窗格可以执行自主命令。助手可以读取项目中的 UTF-8 文件、精确替换内容，再通过该窗格复测。接管的程序、显式启动的程序、带自定义启动参数的 shell、Git Bash、WSL 以及其他系统上的窗格，首版提供聊天和附带终端上下文。

任务始终绑定启动时的窗格。文件工具以任务启动时的目录为准，点击“继续任务”也沿用该目录。发送新请求时使用窗格当前目录。整个应用同时只运行一个任务。隐藏面板时任务继续运行。关闭目标窗格会取消任务，并清除该窗格的对话和草稿。对话仅保存在内存中，也可点“新建对话”清空。

点击消息、提示或工具旁的复制图标，可复制完整内容。工具会复制名称、参数和完整输出，折叠时也可复制。长回复会复制所有分块；Markdown 复制原文。普通文本、工具输出和上下文预览还可选中后按 Ctrl+C（macOS 为 Cmd+C）；预览也有复制全文按钮。

AI 输入框获得焦点后，按 Alt+↑ 调回上次提交的输入，Alt+↓ 切换到较新的输入；模型旁的上下箭头按钮也可切换，并将焦点交给输入框。调回后可修改再发送，切换到最新一条之后会恢复尚未发送的草稿。普通上下方向键仍用于多行光标移动。输入历史属于当前窗格的当前对话，新建对话或退出应用时清空；调回历史不会自动发送。

已有程序运行时，助手会等待。交互程序和密码输入需要人工接管。准备执行命令时，助手会先清除提示符下未提交的输入，包括 PowerShell 的续行草稿。这份草稿不会恢复。Git 命令、未知命令、复合命令、破坏性操作、提权、全局安装、推送和部署默认会要求确认。开启自动允许后会直接执行。拒绝后会把拒绝结果返回模型，不执行该操作。

点击停止，或在终端输入、粘贴、按 Ctrl+C，都会取消后续 AI 操作，并尝试用 Ctrl+C 中断当前命令。中断期间到达的输入会等到 shell 返回提示符后再发送。程序忽略 Ctrl+C 时，可再次中断或关闭窗格。停止不会撤销已执行的命令或文件修改。每 30 次模型调用暂停一次，点击“继续任务”可再运行 30 次。

模型连接复用已有的 `curl` 程序；程序缺失或连接失败会显示错误。

长回复采用分块文本显示，完整内容保留；流式输出先显示文本，较短回复完成后显示 Markdown。刷新会合并，终端进程检查放在后台，减少对输入和滚动的影响。

从助手齿轮打开 AI 设置时，窗口会直接绘制 AI 页。切换模型不会重设无关的终端参数或重新扫描查找历史；首次创建独立设置窗口仍有 Windows 自身的开销。
